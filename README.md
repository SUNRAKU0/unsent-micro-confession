## The entry

```
To: my first love
I still remember your wifi password. I never use it. I just like knowing I could.
```

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the confession to `out/entry.txt`.
